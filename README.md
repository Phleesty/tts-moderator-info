# 🛡️ Полное руководство модератора по управлению Twitch TTS

Интерактивная нейросетевая озвучка на базе **Fish Audio S2.1** и **Yandex SpeechKit** для Streamer.bot.  
Здесь собраны все команды управления, примеры для быстрого копирования в чат и **полный каталог всех 42 голосов**.

> [!TIP]
> Каждая команда оформлена в **отдельный блок кода**. Нажмите кнопку **Copy** в правом верхнем углу блока, чтобы мгновенно скопировать команду и вставить её в чат Twitch.

<a id="features"></a>
## 🌟 Главные возможности системы

* **Многопоточный фоновый конвейер**: Пока звучит одно сообщение, следующие заказы генерируются параллельно в фоне (до 3 одновременных потоков). Озвучка играет плавно и без задержек.
* **Гарантированный возврат баллов Twitch (Refund)**: Если заказ отменён из-за превышения длины (`!ttslimit`), очистки очереди (`!ttsclear`), паузы или сбоя сети — баллы канала **автоматически возвращаются зрителю**. Баллы списываются (`Fulfill`) только после успешного завершения воспроизведения.
* **Умная обрезка текста (Smart Truncation)**: Для команд чата `!tts` длинные сообщения аккуратно завершаются по границе слова или знаку препинания, не обрывая слова на полубукве.
* **Мгновенная реакция на модерацию**: При удалении сообщения модератором или бане зрителя TTS автоматически отменяется, а звучащее аудио моментально глушится в OBS.
* **Автофильтрация смайликов 7TV, BTTV, FFZ и Twitch**: Смайлики чата вырезаются из текста, чтобы бот не зачитывал технические названия.
* **Умная нормализация чисел и ударений**: Числительные вроде `4-го уровня` озвучиваются как *«четвёртого уровня»*, а знак `+` позволяет ставить ударения (`зам+ок`).
* **Резервный голос (Fallback)**: При сбое или задержке внешнего сервера Fish Audio бот автоматически озвучивает фразу через надежный дикторский голос Yandex (`марина`).

<a id="roles"></a>
## 🔑 Права доступа (Кто может управлять)

Управлять настройками озвучки могут:
1. **Стример (Broadcaster)** и главный администратор (`adminUser`).
2. **Менеджеры TTS (Модераторы)** — участники группы `TTS Managers` в Streamer.bot.

> [!NOTE]
> Все команды можно отправлять **в чат трансляции** или **в личные сообщения (Whisper) боту**. Через ЛС команды выполняются абсолютно приватно.

<a id="pause"></a>
## ⏸️ Глобальная Пауза (`!ttsoff` / `!ttson`)

Позволяет временно заглушить озвучку во время важных сюжетных моментов, звонков или катсцен без сброса прав доступа:

Поставить TTS на паузу:
```text
!ttsoff
```

Снять TTS с паузы:
```text
!ttson
```

> [!NOTE]
> Во время паузы **Стример и Менеджеры TTS могут говорить всегда**. Заказы за баллы канала во время паузы автоматически отменяются с возвратом баллов.

<a id="blacklist"></a>
## 🚫 Черный список нарушителей (`!ttsban` / `!ttsunban`)

Черный список имеет **абсолютный приоритет** над любыми ролями (VIP, сабы, баллы). Забаненный пользователь не сможет заказать озвучку.

Забанить пользователя в TTS (с указанием причины):
```text
!ttsban @spammer спам звуками
```

Забанить пользователя без указания причины:
```text
!ttsban @spammer
```

Разбанить пользователя в TTS:
```text
!ttsunban @spammer
```

Посмотреть список забаненных пользователей:
```text
!ttsban list
```

```text
!очистить
```

<a id="access-control"></a>
## 🚪 Управление доступом, таймерами и квотами (`!ttson` / `!ttsoff`)

### 1. Персональный доступ зрителю

Выдать бессрочный доступ зрителю:
```text
!ttson @username
```

Выдать временный доступ на 15 минут:
```text
!ttson @username 15m
```

Выдать временный доступ на 2 часа:
```text
!ttson @username 2h
```

Выдать временный доступ на 7 дней:
```text
!ttson @username 7d
```

Выдать комбинированный таймер (1 час 30 минут):
```text
!ttson @username 1h30m
```

Продлить текущий таймер пользователя на 30 минут:
```text
!ttson @username +30m
```

Уменьшить текущий таймер пользователя на 15 минут:
```text
!ttson @username -15m
```

Выдать квоту на 5 сообщений:
```text
!ttson @username 5
```

Выдать квоту на 50 сообщений:
```text
!ttson @username 50
```

Установить лимит 3 сообщения за один стрим (сбрасывается каждый стрим):
```text
!ttson @username 3/stream
```

Комбинированный доступ: 50 сообщений на 30 дней:
```text
!ttson @username 30d 50
```

Забрать персональный доступ и аннулировать все квоты:
```text
!ttsoff @username
```

---

### 2. Массовое управление категориями и ролями

Включить доступ для подписчиков (Subscribers):
```text
!ttson subs
```

Выключить доступ для подписчиков:
```text
!ttsoff subs
```

Включить доступ для VIP-зрителей:
```text
!ttson vips
```

Выключить доступ для VIP-зрителей:
```text
!ttsoff vips
```

Включить доступ для модераторов канала:
```text
!ttson mods
```

Выключить доступ для модераторов:
```text
!ttsoff mods
```

Включить доступ абсолютно всем зрителям чата:
```text
!ttson all
```

Выключить доступ для всех зрителей:
```text
!ttsoff all
```

Включить награду Twitch за баллы:
```text
!ttson reward
```

Выключить награду Twitch за баллы:
```text
!ttsoff reward
```

Включить чтение всех смайликов (отключить фильтрацию):
```text
!ttson emotes
```

Выключить чтение смайликов (включить фильтрацию смайлов 7TV/BTTV/FFZ):
```text
!ttsoff emotes
```

Сбросить персональные доступы ВСЕХ зрителей:
```text
!ttsoff all_users
```

<a id="voice-management"></a>
## 🎙️ Управление голосами (`!ttsvoice`, `!ttsaddvoice`, `!ttsdelvoice`)

### 1. Просмотр и главные голоса канала

Посмотреть список доступных голосов:
```text
!ttsvoices
```

Сменить главный голос канала по умолчанию:
```text
!ttsvoice default спанч боб
```

Сменить резервный голос (Fallback) на случай сбоя Fish Audio:
```text
!ttsvoice fallback марина
```

---

### 2. Персональные голоса зрителей

Выбрать себе персональный голос (для зрителя):
```text
!ttsvoice папич
```

Назначить персональный голос зрителю (для модератора):
```text
!ttsvoice @username мэд
```

Сбросить персональный голос зрителя на дефолтный:
```text
!ttsvoice reset @username
```

Сбросить персональные голоса ВСЕХ зрителей:
```text
!ttsvoice reset all
```

---

### 3. Добавление и удаление голосов в каталог

Добавить или обновить голос Fish Audio:
```text
!ttsaddvoice соник fish 9df551c5634f4c4f9c9266a439d1154a 1.0
```

Добавить или обновить голос с пробелом в названии:
```text
!ttsaddvoice "дед инсайд" fish d6363192030849b381f80c2ae10741d7 1.0
```

Добавить или обновить голос Yandex SpeechKit:
```text
!ttsaddvoice диктор yandex filipp neutral 1.0
```

Удалить голос из каталога:
```text
!ttsdelvoice соник
```

## 🔊 Управление громкостью (`!ttsvolume`)

Узнать текущую общую громкость TTS:
```text
!ttsvolume
```

Установить общую громкость на 75%:
```text
!ttsvolume 75%
```

Установить общую громкость (значение от 0.0 до 1.0):
```text
!ttsvolume 0.5
```

Прибавить общую громкость на 15%:
```text
!ttsvolume +15%
```

Убавить общую громкость на 10%:
```text
!ttsvolume -10%
```

Откалибровать громкость конкретного голоса (сделать тише до 85%):
```text
!ttsvolume @папич 85%
```

Откалибровать громкость конкретного голоса (сделать громче до 115%):
```text
!ttsvolume @бист 115%
```

Сбросить калибровку громкости голоса на стандартную (100%):
```text
!ttsvolume @папич reset
```

<a id="normalization"></a>
## 🎛️ Автоматическая нормализация звука (`!ttsnormalize`)

Выравнивает пиковую громкость аудиофайлов WAV до 95% (запас усиления до 8.0x / +18 dB), чтобы тихие голоса звучали так же громко и разборчиво, как основные.

Узнать текущий статус авто-нормализации:
```text
!ttsnormalize
```

Включить авто-нормализацию:
```text
!ttsnormalize on
```

Выключить авто-нормализацию:
```text
!ttsnormalize off
```

<a id="silent-mode"></a>
## 🤫 Тихий режим (`-s`) и управление через ЛС (Whisper)

### 1. Приватное управление через ЛС (Whisper)
Отправьте команду в личные сообщения боту на Twitch:
```text
/w ИмяБота !ttsvoice @user папич
```
```text
/w ИмяБота !ttsvolume 70%
```
```text
/w ИмяБота !ttson emotes
```
* Бот выполнит команду **на 100% приватно**, не отправляя сообщений в публичный чат.

### 2. Тихий режим в общем чате (`-s`)
Добавьте флаг `-s` в конце любой команды, чтобы бот применил действие без ответа в чат:

Прибавить громкость молча:
```text
!ttsvolume +10% -s
```

Сменить голос по умолчанию молча:
```text
!ttsvoice default спанч боб -s
```

Выдать доступ зрителю молча:
```text
!ttson @user 1h -s
```

Изменить стоимость награды молча:
```text
!ttscost 1000 -s
```

Добавить слово в словарь молча:
```text
!ttsdict add спс = спасибо -s
```

<a id="emotions"></a>
## 🎭 Эмоции, смех и теги интонаций для зрителей

Зрители могут управлять подачей голоса, указывая теги в квадратных скобках `[...]`:

### 1. Звуковые эффекты и дыхание (Fish Audio)
* `[смех]`, `[смеется]`, `[хохочет]` — живой смех персонажа
* `[хихикает]`, `[смешок]` — легкое хихиканье
* `[шепот]`, `[шёпот]` — произнести фразу таинственным шепотом
* `[вздох]`, `[тяжелый вздох]` — глубокий вздох перед фразой
* `[зевок]`, `[зевает]` — зевание от усталости
* `[плач]`, `[рыдает]`, `[всхлип]` — плачущий тон
* `[крик]`, `[орет]`, `[кричит]` — эмоциональный выкрик
* `[стон]`, `[стонет]` — стонущий голос
* `[одышка]`, `[пыхтит]` — тяжелое дыхание после бега
* `[кашель]`, `[прокашлялся]` — покашливание перед речью
* `[храп]`, `[храпит]` — звук храпа
* `[пауза]`, `[длинная пауза]` — сделать выразительную паузу между словами
* `[смех в зале]`, `[фоновый смех]` — эффект закадрового смеха аудитории

### 2. Эмоциональные состояния
* `[радость]`, `[весело]`, `[счастлив]` — позитивная и радостная интонация
* `[злость]`, `[злой]`, `[сердито]`, `[ярость]` — грозная агрессивная подача
* `[грусть]`, `[печаль]`, `[грустно]` — меланхоличный тон
* `[восторг]`, `[возбужденно]` — восторженный энергичный голос
* `[спокойно]`, `[спокойный]` — расслабленный нейтральный тон
* `[страх]`, `[испуг]`, `[страшно]` — напуганная, дрожащая интонация
* `[удивление]`, `[шок]` — удивленный возглас
* `[сарказм]`, `[ирония]` — саркастичная подача
* `[гордость]`, `[гордо]` — уверенная гордая интонация
* `[смущение]`, `[смущенно]` — застенчивый голос

### 3. Естественный смех
Если зритель напишет `хахаха`, `ахахаха`, `аххаха`, `пхаха`, `хехе`, `xaxaxa` (любой длины), нейросеть автоматически сымитирует живой смех без скобок.

## ⚡ Сводная шпаргалка быстрых команд

| Задача | Команда чата |
| :--- | :--- |
| **Озвучить текст в чате** | `!tts Привет стример!` *(или `!ттс`)* |
| **Поставить / снять с паузы** | `!ttsoff` / `!ttson` |
| **Пропустить текущее сообщение** | `!ttsskip` *(или `!скип`)* |
| **Очистить всю очередь с возвратом баллов**| `!ttsclear` *(или `!очистить`)* |
| **Забанить / разбанить в TTS** | `!ttsban @user [причина]` / `!ttsunban @user` |
| **Посмотреть забаненных** | `!ttsban list` |
| **Дать бессрочный доступ** | `!ttson @user` |
| **Дать доступ на время** | `!ttson @user 15m` / `!ttson @user 2h` / `!ttson @user 7d` |
| **Выдать квоту сообщений** | `!ttson @user 5` *(5 сообщений)* / `!ttson @user 3/stream` |
| **Забрать индивидуальный доступ** | `!ttsoff @user` |
| **Сбросить доступы ВСЕХ зрителей** | `!ttsoff all_users` |
| **Включить для сабов / VIP / всех** | `!ttson subs` / `!ttson vips` / `!ttson all` |
| **Вкл / Выкл награду за баллы** | `!ttson reward` / `!ttsoff reward` |
| **Вкл / Выкл чтение смайликов** | `!ttson emotes` / `!ttsoff emotes` |
| **Сменить стоимость награды** | `!ttscost 1000` *(или `!стоимость 1000`)* |
| **Сменить лимит символов** | `!ttslimit 200` *(или `!лимит 200`)* |
| **Список всех голосов** | `!ttsvoices` *(или `!голоса`)* |
| **Выбрать себе голос (для зрителя)** | `!ttsvoice папич` |
| **Сменить главный голос канала** | `!ttsvoice default спанч боб` |
| **Сменить резервный голос (Fallback)**| `!ttsvoice fallback марина` |
| **Назначить голос зрителю** | `!ttsvoice @user папич` |
| **Сбросить голос зрителя** | `!ttsvoice reset @user` *(или `!ttsvoice @user default`)* |
| **Сбросить голоса всех зрителей** | `!ttsvoice reset all` |
| **Узнать общую громкость** | `!ttsvolume` |
| **Изменить общую громкость** | `!ttsvolume 75%` / `!ttsvolume +10%` / `!ttsvolume -15%` |
| **Откалибровать громкость голоса** | `!ttsvolume @папич 85%` / `!ttsvolume @бист reset` |
| **Вкл / Выкл авто-нормализацию звука**| `!ttsnormalize on` / `!ttsnormalize off` / `!ttsnormalize` |
| **Посмотреть словарь замен** | `!ttsdict list` *(или `!словарь`)* |
| **Добавить слово в словарь** | `!ttsdict add спс = спасибо` |
| **Удалить слово из словаря** | `!ttsdict remove спс` |
| **Посмотреть белый список смайлов** | `!ttswhitelist` *(или `!вайтлист`)* |
| **Добавить смайл в белый список** | `!ttswhitelist add Pog` |
| **Удалить смайл из белого списка** | `!ttswhitelist remove Pog` |
| **Добавить голос в каталог** | `!ttsaddvoice соник fish <ref_id> 1.0` |
| **Удалить голос из каталога** | `!ttsdelvoice соник` *(или `!удалитьголос`)* |
| **Назначить / снять менеджера TTS** | `!ttsmanager add @user` / `!ttsmanager remove @user` |
| **Выполнить команду молча (без спама)**| Добавить `-s` в конце любой команды (`!ttsvolume 70% -s`) |
